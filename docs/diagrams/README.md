# Diagramas draw.io de alto nivel

Los tres diagramas son propuestas de diseño, editables en diagrams.net mediante
Archivo → Abrir. El XML está sin comprimir y no depende de recursos remotos.

| ID | Archivo | Interpretación |
| --- | --- | --- |
| D1 | [Contexto](D1-context.drawio) | Actores, host, sistema y oráculo externo |
| D2 | [Componentes](D2-components.drawio) | Contratos y dependencias del MVP; extensión futura separada |
| D3 | [Validación](D3-validation.drawio) | Fixtures, ambos motores, normalización y gate |

Los IDs C1–C8 enlazan con [arquitectura](../architecture/high-level-design.md).
FR/NFR enlazan con [requisitos](../requirements/specification.md).
Las aristas indican intercambios propuestos, no llamadas observadas ni despliegues.
